# digital-forensics-investigation
A simulated digital forensics investigation of a cloud attack resulting in the unconsensual posting of pictures on a social media account.

In this project, I analyzed simulated evidence to determine whether the social media company, MyFace, experienced a cyberattack that resulted in the uploading of a user’s photos. I analyzed netstat TCP, UDP, and local host ports on a server, as well as Bulk Extractor and Xplico results. I also analyzed command prompt logs, Wireshark results, and MailXaminer results on the defendant's personal computer. I then completed a Digital Evidence Forensics Report, a summary of findings, and a recommendation to the client, MyFace.

*Note: To adhere to academic integrity policies, this repository contains original work for a university coursework assignment. The specific course numbers and direct assignment prompts have been omitted.*
