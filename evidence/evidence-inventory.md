## Evidence Description
### E-001 — Windows Forensic Image
A forensic image representing the Windows workstation assigned to John Smith.
The image will serve as the primary source of evidence for the investigation.

### E-002 — Windows Event Logs
Windows event logs will be examined for authentication activity, system events,
and other events relevant to the investigation timeline.

### E-003 — Windows Registry Artifacts
Registry artifacts will be examined for information related to user activity,
connected devices, system configuration, and other relevant activity.

### E-004 — User Profile Artifacts
User profile information will be examined to identify accounts, files,
application activity, and other artifacts associated with the suspected user.

### E-005 — File System Artifacts
File system artifacts will be examined for file creation, modification,
access, deletion, and other relevant activity.

### E-006 — USB Device Artifacts
USB-related artifacts will be examined to determine whether external storage
devices were connected to the workstation.

### E-007 — Browser Artifacts
Browser artifacts will be examined for activity that may be relevant to the
investigation.

### E-008 — File Metadata
File metadata will be examined to identify timestamps, file types, authorship
information, and other information that may assist with the investigation.
